Instalación rápida

La forma más sencilla de instalar Ziha Rueditas en una máquina Debian o Ubuntu es usar el instalador automático.

Instalación automática 
curl -fsSLO https://erickdmp.github.io/ziha_rueditas/install.sh && sudo bash install.sh
Ejecutar Ziha Rueditas 
ziha_rueditas

Instalación manual

Si prefieres configurar el repositorio APT manualmente, puedes seguir estos pasos:

Descargar clave 
curl -fL https://erickdmp.github.io/ziha_rueditas/ziha-archive-key.asc -o /tmp/ziha-archive-key.asc
Configurar repositorio 
sudo install -d -m 755 /etc/apt/keyrings
sudo install -m 644 /tmp/ziha-archive-key.asc /etc/apt/keyrings/ziha-archive-key.asc
Contenido de ziha.sources 
Types: deb
URIs: https://erickdmp.github.io/ziha_rueditas/
Suites: ./
Signed-By: /etc/apt/keyrings/ziha-archive-key.asc

Características

Fondos de Ziha

Incluye tres fondos personalizados: retrato, lluvia y azotea.

Idioma español

Configura el sistema en español de España.

Teclado español

Permite establecer el teclado en distribución española.

Repositorio APT

Distribución del paquete mediante GitHub Pages y repositorio firmado.

Galería

Seguridad y firma GPG

El repositorio APT de Ziha Studio está firmado digitalmente para que el sistema pueda verificar la autenticidad de las publicaciones.
